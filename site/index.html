Voice Chat for Beat Saber 1.40.8

Talk with other players in multiplayer lobbies. Players talk directly through the game's own multiplayer connection, so there is no server to run or sign up for.

Download .qmod (1.40.8) How to install

Features

  • Voice in multiplayer lobbies, with anyone else who has the mod.
  • Mic mute button in the lobby. Tap it to mute or unmute yourself. Your state is kept between sessions.
  • No server needed. Voice is sent as packets over the game's multiplayer connection.
  • Works on any multiplayer server, as long as the other players have the mod.

Install

  1. Install Beat Saber 1.40.8 and BSIPA/QuestPatcher (or your usual modding tool).
  2. Install the dependencies the mod needs: beatsaber-hook, bsml, and multiplayercore.
  3. Download the .qmod file above and open it with QuestPatcher, or copy it into your mods folder.
  4. Start Beat Saber, join a multiplayer lobby, and check the mic button next to your name.

Privacy

Voice goes directly between players in the lobby and is not encrypted end to end. Only talk with people you trust. Don't rely on this for secure communication.
